# Grit: Суровое выживание

Мод для **Minecraft 1.20.1 (Fabric)**: выживание жёстче, но вайб ванилы не ломается.
Никаких новых шкал на экране — только ванильные эффекты, звуки и короткие подписи над хотбаром.

## Механики

### 🦴 Переломы
Падение с уроном от 3 сердец может сломать ногу: −25% скорости и −15% скорости атаки на 3 минуты.
Ещё одно тяжёлое падение — перелом II. **Шина** сокращает заживление до 20 секунд.

### 🌑 Страх темноты
Долго находиться в кромешной тьме под землёй или под крышей — тяжело (шаг стадии по умолчанию 45 сек):
1. шёпоты пещеры звучат прямо рядом;
2. слышно собственное сердцебиение;
3. зрение пульсирует (ванильная «Тьма»), слабость;
4. паника — ещё и утомление.

Любой свет быстро снимает напряжение. Ночное зрение защищает полностью. Работает только в Верхнем мире.

### 🎒 Тяжёлая ноша
Руда, блоки металлов, наковальни, обсидиан — тяжёлые; камень, земля, гравий, брёвна,
ящики и мешки Farmer's Delight — громоздкие. Перегруз замедляет на 12%, сильный перегруз — на 25%
и быстрее изматывает при беге. Шалкеры и эндер-сундук — честный способ возить добычу.
Списки — в тегах `#grit:heavy` и `#grit:bulky` (легко переопределить датапаком).

### 🌕 Полнолуние
Каждую 8-ю ночь (ванильная полная луна) мобы, появившиеся этой ночью, получают +30% здоровья,
+10% скорости, +20% урона и +50% дальности преследования. На закате воют волки.

## Предметы

| Предмет | Рецепт | Действие |
|---|---|---|
| Шина | палки по краям, нить в центре (`S S / STS / S S`) | перелом заживает за 20 с |

Во вкладке «Инструменты» творческого режима.

## Настройка

`config/grit.json` создаётся при первом запуске. Каждую механику можно выключить или подкрутить:
порог и длительность перелома, длину стадий страха и порог света, пороги веса, бонусы полнолуния.

## Совместимость

- **Tough As Nails** — Grit не трогает температуру и жажду, механики не пересекаются.
- **Serene Seasons** — Grit не трогает сезоны, погоду и рост растений.
- **Farmer's Delight Refabricated** — Grit не трогает еду и голод; ящики и мешки FD считаются громоздкими
  (записи тега необязательные: без FD ничего не ломается).
- Без миксинов — совместим с Sodium, Iris, Lithium и т.п.
- Нужен **и на сервере, и на клиенте**. Требуется Fabric API.

## Сборка на GitHub (без установки чего-либо на компьютер)

1. Зарегистрируйтесь на [github.com](https://github.com) и войдите.
2. Справа вверху **«+» → New repository**. Название, например, `grit-mod`, видимость Public или Private —
   не важно. Галочки «Add a README» **не ставьте**. Нажмите **Create repository**.
3. Распакуйте архив с модом. На странице нового репозитория нажмите ссылку **«uploading an existing file»**.
4. Откройте распакованную папку `grit` и перетащите в окно браузера **всё её содержимое**
   (`src`, `gradle`, `build.gradle`, `gradle.properties`, `settings.gradle`, `gradlew`, `gradlew.bat`, `README.md`) —
   именно содержимое, а не саму папку `grit`. Внизу нажмите **Commit changes**.
5. Проверьте, что в корне репозитория есть файл `build.gradle` и папка `gradle/wrapper` с файлом
   `gradle-wrapper.jar`. Если файлы оказались внутри папки `grit/` — удалите репозиторий и повторите шаг 4.
6. Создайте файл сборки: **Add file → Create new file**. В поле имени впишите ровно
   `.github/workflows/build.yml` (слэши сами превратятся в папки) и вставьте содержимое файла
   `.github/workflows/build.yml` из архива. Нажмите **Commit changes**.
   (Браузер часто не загружает скрытые папки, начинающиеся с точки, поэтому этот файл создаётся вручную.)
7. Откройте вкладку **Actions**. Если GitHub спросит — нажмите **«I understand my workflows, go ahead and enable them»**.
   Сборка запустится сама после коммита; если нет — слева выберите **build → Run workflow → Run workflow**.
8. Подождите 3–6 минут, пока у запуска не появится зелёная галочка ✅.
9. Нажмите на запуск, внизу страницы в разделе **Artifacts** скачайте `grit-mod`. Это zip, внутри —
   `grit-1.0.0.jar`.
10. Положите `grit-1.0.0.jar` в папку `mods` вместе с **Fabric API**.

Если появился красный крестик ❌ — нажмите на запуск → **build** → раскройте шаг с ошибкой и скопируйте
текст (обычно последние 30–50 строк перед `BUILD FAILED`).

Чтобы пересобрать после изменений: отредактируйте файл прямо на GitHub (иконка карандаша) и сделайте
Commit — сборка запустится снова.

## Сборка локально

Нужен JDK 17+: `./gradlew build` (Windows: `gradlew.bat build`) → `build/libs/grit-1.0.0.jar`.
